## 3. 关键决策理由

### 3.1 为什么选 RP2040-Tiny

- 便宜、好买（嘉立创商城约 28 元），RP2040 生态成熟（QMK 官方支持、UF2 拖拽烧录）。
- **20 个 GPIO 刚好覆盖矩阵**：14 列 + 5 行 = 19 根线，余 1 个 IO。
- 模块为半孔主边、可直接焊接到载体板（castellated），厚度小。
- USB 采用**分体式设计**：模块自带 8 针 FPC（D+/D−、VSYS、GND、RUN、BOOT），USB-C 座放在键盘 PCB 上，通过 FPC 连接，可降低整板厚度。
- 对比：旧 lh60 用 ATmega32U4（LQFP-48），方案老、价格/供货不占优；其他 RP2040 模块（Pico、Tiny2040 等）IO 引出或尺寸不如 Tiny 合适。

### 3.2 为什么 18×17 mm 间距

- Choc 生态的"紧凑标准"就是 18×17（Kailh 官方键帽键单元 18×17；MBK、Chocfox、LDSA 均按此制作）。
- 19.05 是 MX 间距；PH60 量产矮轴板用 19.05，但用户确认本板做 18。
- 板宽：15 列 × 18 = **270 mm**；高：5 行 × 17 = **85 mm**（不含边距）。

### 3.3 为什么 Choc V1/V2 双兼容座

- V1/V2 外壳同为 15×15 mm，定位板开孔同为 14×14（与 MX 通用）。
- 但 V1 中心柱 3.4 mm / V2 中心柱 5.0 mm，**老 V1 专用 PCB 塞不下 V2**；双兼容座同时吃两种。
- V1 为 5 针（含固定脚）、Choc 专用轴心；V2 为 3 针、MX 十字轴心，键帽不互通（本板无刻键帽，不影响）。

### 3.4 配列支持集（简化版）

同一 PCB 预埋全部热插拔座，通过旋转避让，**不焊接即可切换**：

| 区域 | 支持 |
|---|---|
| Backspace | 2u 一体（倒置）＋ 分裂 1u+1u（正置） |
| Enter | ANSI 2.25u ＋ ISO 1.25u |
| LShift | 2.25u 一体 ＋ 分裂（1.25u + 1u Fn） |
| RShift | 2.75u 一体 ＋ 分裂 1.75u+1u(↑) ＋ ISO（1u \ + 1.75u） |
| 底排 | 方向键版（2.75u 空格 + Fn Alt Win ←↓↑→）＋ 标准版（6.25u 空格 + Fn Alt Win Ctrl） |

### 3.5 矩阵共享规则（参考旧 lh60）

- 共享同一逻辑键的座接**同一矩阵节点**（同一颗二极管）。
- 旧板实例：2u Backspace 与分裂右半（Del）共享 D65；ANSI RShift/分裂 RShift/ISO `\` 三个座共享 COL13；空格 3u 与 6.25u 共享。
- 新板 68 个节点、68 颗二极管；空闲节点 R3/C14、R5/C13。
- 详细表格见 [layout-v2.md](layout-v2.md)。
