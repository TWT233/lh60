# LH60 Socket B.CrtYd Design

## Goal

为 `lib/lh60-sockets/` 中的自有 footprint 增加真实的底面座子占地，使 KiCad 能通过
`B.CrtYd` 检测座子实体的装配干涉，而不是使用开关本体或键帽外框作为 courtyard。

## Scope

- 更新 7 个 Gateron LP 单座 footprint：
  - `Gateron-LP-Hotswap-Socket-1U`
  - `Gateron-LP-Hotswap-Socket-1.25U`
  - `Gateron-LP-Hotswap-Socket-1.5U`
  - `Gateron-LP-Hotswap-Socket-1.75U`
  - `Gateron-LP-Hotswap-Socket-2U`
  - `Gateron-LP-Hotswap-Socket-2.25U`
  - `Gateron-LP-Hotswap-Socket-2.75U`
- 更新 1 个 Gateron LP + Choc V1 双座 footprint：
  - `Gateron-LP-or-ChocV1-Hotswap-Socket-1U`
- 不修改 pad、孔位、F.SilkS 键帽框、网络编号或其他 KiCad 工程文件。

## Courtyard Rule

- courtyard 只表示 PCB 底面的热插拔座实体，不表示顶面的开关外壳、键帽或定位板。
- 以塑胶主体、两端金属端子与完整 land pattern（SMD 焊盘、铜桥、PTH 焊环）
  的几何并集为基准，整体向外偏移 0.25mm。
- 使用 `B.CrtYd`、0.05mm 线宽、无填充的闭合轮廓。
- 直边、斜边、凹槽和圆弧均按源轮廓保留，不允许用外接矩形代替。
- KiCad 中使用闭合 `fp_poly` 表达偏移后的几何并集；圆弧离散的最大弦误差不超过
  0.01mm，坐标保留到 0.001mm。
- 双座 footprint 保留两套独立真实轮廓，不画一个包围两者的大轮廓。
- 不增加 `F.CrtYd`。

## Gateron LP Geometry

参考 `docs/O1CN01bK2mBI1wGI35HnOHL_!!51786280.jpg`：

- 图纸最大外形：15.1mm × 5.4mm，包含两侧金属端子。
- siderakb 源封装 `B.Fab` 是塑胶主体的闭合轮廓，与图纸 11.85mm × 5.40mm
  主体一致。原始轮廓按以下顺序闭合：
  - `(-6.815, 2.525)`
  - `(-2.595, 2.525)`
  - `(-0.395, 3.575)`
  - `(5.025, 3.575)`
  - `(5.025, 7.925)`
  - `(0.405, 7.925)`
  - `(0.405, 7.700)`
  - `(-0.395, 7.700)`
  - `(-0.395, 7.925)`
  - `(-2.595, 6.875)`
  - `(-6.815, 6.875)`
- 图纸两侧端子高度为 2.17mm；结合源 pad 中心，端子实体矩形为：
  - 左端子：`x = [-8.445, -6.815]`，`y = [3.615, 5.785]`
  - 右端子：`x = [5.025, 6.655]`，`y = [4.665, 6.835]`
- Gateron `B.CrtYd` 是上述塑胶多边形、两个端子矩形与完整 land pattern 的并集
  向外偏移 0.25mm。
- 偏移轮廓保留原塑胶主体的斜边与中间凹槽；端子外角使用 0.25mm 圆角连接，
  不填补塑胶主体上下方的空白区。

`CPG135001S30` 官方/LCSC 图纸：

- 图纸最大外形：13.15mm × 6.85mm，包含两端金属端子。
- siderakb 源封装 `B.SilkS` 是 9.55mm × 6.85mm 塑胶主体的真实轮廓。
- 轮廓中的直线与圆弧全部保留，具体源几何为：
  - 左侧竖边：`(-7.275, 1.825)` 到 `(-7.275, 5.775)`

  - 上内圆角：`(-3.425, 1.450)` 经 `(-3.159835, 1.559835)` 到 `(-3.050, 1.825)`

- 偏移时保留原有圆弧；端子外角使用 0.25mm 圆角连接，不填补主体内凹区。

## Derived Clearance

座体之间的间距仍按塑胶主体与端子并集计算；courtyard 最终边界另外包含完整
land pattern：

- Gateron LP 与旋转 180° 的 Choc V1 实体最近距离：5.025mm。
- 两套实体各自向外偏移 0.25mm 后，courtyard 最近距离：4.525mm。
- 两套 courtyard 不相交，双座同时贴装不会产生 courtyard overlap。
- 该间距只用于验证双座内部共存；与相邻键位的 courtyard 仍由 KiCad DRC 检查。

## Expected Behavior

- Gateron 单座 footprint 只显示一套沿真实座体外形的底面 courtyard。
- 双座 footprint 显示上下分离的两套真实外形 courtyard：
  - 下方为 Gateron LP 0°。
  - 上方为 Choc V1 180°。
- 两套轮廓之间保留真实空白区，表示两种座子可同时贴装。
- 多配列 footprint 靠得过近时，KiCad courtyard DRC 应报告真实的底面座子装配冲突。

## Verification

1. 使用 Konnect library 工具读取每个 footprint，确认 `B.CrtYd` 为闭合真实轮廓：
   - Gateron 单座：1 套闭合轮廓。
   - 双座：2 套独立闭合轮廓。
2. 确认所有线段/圆弧线宽为 0.05mm，源轮廓与端子尺寸符合本规格，整体外扩
   0.25mm，曲线离散误差不超过 0.01mm。
3. 确认 pad 数量、pad 坐标和钻孔尺寸未变化。
4. 用 KiCad CLI 或 Konnect 导出 footprint/测试板视图，确认 courtyard 在底层且轮廓可见。
5. 检查 courtyard 不覆盖两种座子之间、塑胶主体凹槽内或端子之间的空白区域。
6. 更新 `lib/lh60-sockets/README.md`，删除“无 courtyard”旧口径并记录真实轮廓规则。
