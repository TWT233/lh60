# LH60 拷问报告 #004：RShift 三方案共存（用户实测）

> 生成：2026-08-14 · grill-with-docs 第四轮

## 1. 用户成果：RShift 三方案已画通

用户在测试工程里放了一行 5 个 Gateron KS33 座子（ai03 mxv2 库，y=145.25625），
共用同一 2.75u 键帽包络（7.625–10.375u），三套互斥方案：

| 方案 | 键 | 中心 (u) | 旋转 |
|---|---|---:|---:|
| A | 2.75u RShift | 9.0 | 0° |
| B | 1.75u Shift + 1u Fn | 8.5 / 9.875 | 180° / −90° |
| C | 1u Fn + 1.75u Shift | 8.125 / 9.5 | 90° / 180° |

关键技巧：两个 1u Fn 座用 ±90° 旋转，让 7.14mm（0.375u）那两对也能塞下。
所有座子已翻面（焊盘在 B.Cu），符合 Gateron 官方"座子焊在 PCB 底部"。

## 2. 验证结果

独立几何计算（ai03 KS33 封装，铜 0.2 / 孔 0.25 间隙）：

| 座对 | 中心距 | 最小余量 |
|---|---|---:|
| C1u ↔ C1.75u | 7.14 mm | +0.40 mm（最紧） |
| B1.75u ↔ A2.75u | 9.53 mm | +0.67 mm |
| A2.75u ↔ C1.75u | 9.52 mm | +1.72 mm |
| B1.75u ↔ B1u | 7.14 mm | +1.45 mm |
| 其余 | ≥16.67 mm | 均 ≥+1.94 mm |

KiCad 10 CLI DRC：仅剩"未画板框"（invalid_outline）一条，无孔/铜冲突。
**三方案共存成立**——这是第一个被画通的多配列冲突区。

## 3. 两个必须处理的点

### 3.1 座子几何来源待定：ai03 vs siderakb（量产验证）

ai03 MX_V2 与 siderakb/beekeeb 的 Gateron LP 座子几何不一致（焊盘位置、孔径、
中心孔 5.1 vs 5.25、THT 引脚有无）。beekeeb 的 Corne GLP 为在售产品，其内嵌封装
与 siderakb 一致；Gateron 官方亦称座子焊板底（B.Cu）。同一摆法换算到 siderakb：

- `HotSwap_THT`（带 2 个 THT 引脚）：4 对冲突（−0.20 mm）；
- `HotSwap_PTH`：仅 7.14 mm 那对差 −0.13 mm，其余 OK。

→ 定稿前需用卡尺实测真实座子，确认以哪版几何为准；若以 siderakb 为准，
当前摆法只需微调（改一个旋转或挪 0.1 mm 级）。

### 3.2 ±90° 座子需配合 ±90° 插轴

Gateron LP 开关引脚在单侧（约 (−4.4,4.7)/(2.6,5.75)），座子旋转 θ 后夹片随之旋转，
开关需同角度插入才能对位。1u Fn 键帽无方向性、无稳定器，实际可用，但需用真实
座子+开关验证 90° 插入能正常卡住。

## 4. 下一步

1. 实测座子几何（卡尺）→ 定 ai03 / siderakb 哪版为准；
2. 验证 90° 插轴；
3. 画板框 → DRC 清零；
4. 其余冲突区（顶排 / Enter / LShift / 底排）按 RShift 同法逐个画通。
