# ADR-0001：平台基线（主控 / 间距 / 轴 / 矩阵）

- 状态：**ACCEPTED**（旧会话决策，本会话沿用，待配列范围确认后复核）
- 日期：2026-08-14
- 背景：lh60 v2 从头重做，旧分支文档已沉淀（现留存于 git 历史）

## 决策

1. **主控**：Waveshare RP2040-Tiny（20 GPIO：GPIO0–15 + GPIO26–29），USB 通过板上 8 针 FPC 分体引出到 PCB 上的 USB-C 座。
2. **键距**：18 mm 横向 × 17 mm 纵向（Choc 紧凑标准），非 MX 的 19.05。
3. **轴**：Kailh Choc V1/V2 矮轴，双兼容热插拔座（kiswitch `SW_Hotswap_Kailh_Choc_V1V2_*`）。
4. **矩阵**：14 列 × 5 行，二极管阳极接列、阴极接座 pad1、座 pad2 接行；共享同一逻辑键的多个座接同一节点。
5. **PCB**：2 层，嘉立创工艺（min track 0.127 / clearance 0.2032 / via 0.5）。
6. **固件**：QMK + RP2040，UF2 拖拽烧录。

## 后果

- 20 个 GPIO 中矩阵占用 19（14 列 + 5 行），余 1 个。
- 18×17 决定了**不能兼容 MX 轴**（除非整板改 19.05，涉及所有几何与键帽生态）。
- Choc V1/V2 座决定了冲突区共存间距的硬约束（见 ADR-0002）。

## 待复核

- "支持多种轴"若指 MX 而非 Choc V1/V2，本 ADR 需整体推翻。

> ⚠️ 2026-08-14（第二轮裁决）：用户改为 **Gateron 矮轴（KS-33）为主**，Choc V1/V2 兼容待验证。
> 本 ADR 的轴 / 键距 / 座子条款整体待复核，见 grill-002；矩阵与主控条款暂不受影响。
