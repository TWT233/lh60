# LH60 v2 配列/矩阵规格

> 分支：`lh60-rp2040-v2`  ·  间距：**18 mm 横向 × 17 mm 纵向**（Choc 标准紧凑间距）
> 轴座：Kailh **Choc V1/V2 双兼容热插拔座**（kiswitch `SW_Hotswap_Kailh_Choc_V1V2_Plated_*`）
> 主控：Waveshare RP2040-Tiny（矩阵用 14 列 + 5 行 = 19 根线，余 1 个 GPIO）
> 键帽：无刻，只关心键位尺寸，不关心区域语义

## 1. 设计原则（用户确认）

1. 所有键位**同时预埋热插拔座**，不是二选一的备选方案。
2. 冲突区域通过**旋转座子（倒置/正置）**交错焊盘解决，参考旧 lh60 的处理。
3. 旧 lh60 支持项更多，本版**简化**为 KLE 里的这套支持集。
4. 共享同一逻辑键的多个座接**同一矩阵节点**（同一颗二极管），参考旧板：
   - 2u Backspace 与分裂 Backspace 右半（Del）共享；
   - ANSI Enter 与 ISO Enter 共享；
   - LShift 一体 2.25u 与分裂右半 1.25u 共享；
   - ANSI RShift 2.75u / 分裂 1.75u / ISO `\` 三个座共享；
   - 分裂 RShift 的 `↑` 1u 与 ISO RShift 1.75u 共享；
   - 空格 2.75u（方向键版）与 6.25u（标准版）共享；
   - 底排 Fn / Alt2 / Win2 两套位置互斥，各自共享节点。

## 2. 键位几何（坐标 = u 单位；mm = x×18 / y×17）

所有行左缘对齐 u=0（对应 mm x=0）。原点取左上角 Esc 键的左缘。

## 3. 矩阵汇总

- 14 列（COL1…COL14）× 5 行（ROW1…ROW5），共 **68 个节点**（70 减 2 空闲）。
- 空闲节点：`R3/C14`、`R5/C13`（备用）。
- 二极管 68 颗（每节点 1 颗）：阳极 → COLx，阴极 → 座 pad1；座 pad2 → ROWy。
- 共享节点一览：

| 节点 | 共享的座 |
|---|---|
| R1/C14 | Backspace 2u + Del(1u) |
| R3/C13 | Enter ANSI(2.25u) + Enter ISO(1.25u) |
| R4/C2 | LShift(2.25u) + LShift 分裂(1.25u) |
| R4/C13 | RShift(2.75u) + RShift 分裂(1.75u) + ISO \ (1u) |
| R4/C14 | ↑(1u) + RShift ISO(1.75u) |
| R5/C4 | Space 2.75u + Space 6.25u |
| R5/C5 | Fn(方向键版) + Fn(标准版) |
| R5/C6 | Alt(方向键版) + Alt(标准版) |
| R5/C7 | Win(方向键版) + Win(标准版) |

## 4. 旋转/避让说明

- Backspace 区：2u 座倒置 180°，两个 1u 座正置。
- R4 右侧（12.25u…15u 内 5 个座）：按旧板方式相邻座旋转 180° 交错焊盘。
- 底排 Space/Fn/Alt/Win 两套位置物理上重叠的部分（如 6.25u 空格开关中心 6.875u 与方向键版 Fn 中心 7.125u），同样旋转交错。
- 详细旋转由 PCB 布板阶段按 DRC 实际判定，以**不短路、可插拔**为唯一标准。

## 5. 卫星轴（plate-mount，定位板开槽）

- 4 × 2u：Backspace / Enter / LShift / RShift（旧 lh60/PH60 先例：LShift、RShift 也上 2u 卫星轴）。
- 1 × 6.25u：空格。
- ISO Enter 不需要卫星轴。

## 6. 外形尺寸（预计）

- 键区：15u × 18mm = **270 mm 宽**；5 行 × 17mm = **85 mm 高**。
- 加边距/安装孔/USB 区后整板约 **276 × 92 mm**（待布板确认）。
- 旧 lh60 外壳（285 × 94.6 mm）**不可复用**，需重新设计外壳与定位板。
