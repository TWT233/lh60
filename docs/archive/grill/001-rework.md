## 1. 目标重述

- **基础目标**：60% 布局键盘，用户 0 焊接即可使用；支持多种配列与多种轴。
- **实现方法**：仿 GH60 单功能区多配列；改为热插拔；冲突用旋转封装解决。

## 3. 与旧 v2（layout-v2.md）的差异

| 区域 | 旧 v2 | 新配列 | 影响 |
|---|---|---|---|
| 顶排右 | Backspace 2u / ~ + Del | 2u / Fn + Caps（几何相同） | 无几何变化，仅语义占位 |
| Enter | ANSI + ISO(1.25×2u) | ANSI + 分裂(Fn + 1.25u) | **ISO 被移除，新增分裂 Enter** |
| LShift | Fn + 1.25u 分裂 | 相同 | 无变化 |
| RShift | 1.75u + ↑ | 1.75u + Fn | 语义占位变化 |
| 底排 | 方向键版 + 标准 6.25u 版 | 仅方向键版（2.25u 空格） | **6.25u 标准空格被移除**；旧版底排存在 4.5mm 座冲突，本就不可行 |
| 矩阵 | 68 节点 / 78 座 | ≈70 节点 / ≈74 座（满矩阵） | 无空闲节点，需复核 |

## 4. 核心技术拷问：旋转能解决冲突吗？

**不能。** 详见 ADR-0002。要点：

- Choc V1/V2 座最小共存中心距 ≈14.6 mm（同向）或 16.6 mm（反向）。
- 本设计冲突区中心距 9–11.25 mm，全部低于下限；旋转 0°/180° 均无法同时满足"焊盘不短路 + 轴孔不重叠 + 座体不相撞"。
- 结论：**冲突区无法全预埋**，只能"按订单装配选择"，或放弃分裂/大键选项。

## 5. 其他风险清单

1. **"多轴"范围未定义**：Choc V1/V2（18×17，推荐）还是 MX/Choc 都要（需 19.05，且 MX 座更宽、冲突更严重，同一位置无法双座）？ADR-0001 假定 Choc 专属。
2. **定位板策略**：多配列 = 多块定位板（每配列一块）；卫星轴为 plate-mount，PCB 无封装。需确认"换配列 = 换定位板 + 移动轴体"可接受。
3. **2.25u 空格键帽**：Choc 生态里 2.25u 键帽（MBK/LDSA）可得但少见，需下单前验证；2.25u 空格需 2u plate-mount 卫星轴 + 对应定位板开槽。
4. **矩阵满负荷**：新配列 ≈70 节点 = 14×5 全用满，无空闲；若后续加功能（如旋钮、编码器）无 IO 余量（RP2040-Tiny 剩 1 GPIO）。
5. **0 焊接定义**：假设为"工厂预装配、用户插轴装帽"；换配列在冲突区需出厂选择，需在售卖/文档中说明。
6. **RP2040-Tiny FPC 分体 USB**：沿用旧设计（D+/D−、VSYS、GND、RUN、BOOT），引脚顺序待 Adapter V1.1 原理图核对。
