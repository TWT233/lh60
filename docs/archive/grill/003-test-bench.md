## 2. 测试工程（已交付，已提交推送）

路径：`test/lh60-test.kicad_pcb`（生成器 `test/generate_test_pcb.py`，可复现）。

内容（全部 19.05 mm 网格、两种真实座子封装内嵌：kiswitch Choc V1/V2 Plated 与
Kailh CPG151101S11）：

1. 四个冲突区（顶排右 / Enter / LShift / RShift）各两组尝试：全 0° 与"大键 180°"。
2. 基准区：两种座子在"最小可共存距离 +0.05 mm"下的参考对，DRC 应干净。
3. 分裂 RShift 歧义区：KLE 原样 `{x:10}` 与右对齐 `{x:12.25}` 两种画法对照。
4. 15u × 5u 网格 + 可自由复制的座子 palette。

KiCad 10 CLI 实测 DRC（min clearance 0.2 / hole-to-hole 0.25）：

| 违规类型 | 数量 | 含义 |
|---|---:|---|
| solder_mask_bridge | 44 | 焊盘过近，阻焊桥缺失 |
| shorting_items | 22 | 不同网络铜焊盘直接重叠（短路） |
| hole_to_hole | 12 | 孔壁重叠/孔距不足 |
| hole_clearance | 9 | 孔与铜间距不足 |
| mirrored_text（警告） | 5 | KaiHua 封装文字镜像，装饰性 |

**结论再次确认**：冲突区（9.53 / 11.91 mm）无论同向还是 180°，DRC 全部报错；
基准区干净。即"旋转 180°"无法让 2u 与分裂座共存于同一 PCB。

## 3. 分裂 RShift 坐标（待用户在看测试图后确认）

KLE `{x:10}` 在绝对坐标语义下右组落在 10–12.75u，与主行 `M < > ?`（9.25–12.25u）重叠。
用户的解释（"左边有 2.25 分裂 LShift"）若指"左组 2.25u + 10 个字母 = 12.25u"，则
正确坐标应为 `x:12.25`。测试工程 E 区把两种画法并排画出，供直观对照；KLE 语义为绝对坐标。
